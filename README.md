🧮 Mi primera calculadora en Python

📌 Descripción

Esta es una aplicación de consola desarrollada en Python como parte de mi proceso de aprendizaje en programación. Permite realizar operaciones matemáticas básicas mediante la entrada de dos números por parte del usuario.

✨ Funcionalidades

- ➕ Suma de dos números.
- ➖ Resta de dos números.
- ✖️ Multiplicación de dos números.
- ➗ División de dos números.
- 🛡️ Validación para evitar la división entre cero.

🛠️ Tecnologías utilizadas

- Lenguaje: Python.
- Editor de código: Visual Studio Code.

🎯 Objetivo del proyecto

Poner en práctica los fundamentos de Python y desarrollar una aplicación funcional que permita aplicar operaciones matemáticas básicas, manejar entradas del usuario y controlar situaciones especiales, como la división entre cero.

📚 Aprendizajes

Con este proyecto practiqué:

- El uso de variables y tipos de datos.
- La recepción de datos mediante "input()".
- Las operaciones aritméticas.
- La conversión de datos numéricos.
- Las estructuras condicionales para validar la división entre cero.
